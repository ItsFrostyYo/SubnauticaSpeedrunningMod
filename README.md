# Race & BetterRNG

Speedrunning Mod for Subnuatica built for the SNSRModLoader that Includes BetterRNG and Filtered Seeds for Practice and Any% BetterRNG Category, aswell as include Racing to compete versus friends (UCE Legal, Main Leaderboard not Legal)

## Local account/server rebuild

The mod rebuild stays local on `main`; the server uses `rebuild/cloudflare-accounts`.
Online features automatically use `https://subnautica-race-api.geonautica.workers.dev`.
There are no connection switches or editable server addresses in the mod settings.
Options > Race contains Google sign-in, account management and sign-out controls.
Old connection/username configuration keys are removed on startup. Account sessions
remain encrypted in a separate file. The old committed build remains available for
the legacy deployment. See the independent Server repository's `docs/SETUP.md`.
